# 💰 Expense Tracker

A modern full-stack Expense Tracker application built to help users manage their personal finances. The application allows users to record income and expenses, manage monthly budgets, and visualize spending through interactive charts.

---

## 🚀 Features

### Authentication
- User Registration
- User Login
- Protected Routes
- Logout

### Dashboard
- Total Balance
- Total Income
- Total Expenses
- Recent Transactions
- Financial Summary Cards

### Transaction Management
- Add Transaction
- Edit Transaction
- Delete Transaction
- Income & Expense Categories
- Transaction History

### Budget Management
- Create Monthly Budget
- Track Budget Usage
- Remaining Budget
- Budget Progress

### Reports
- Income Chart
- Expense Chart
- Category-wise Pie Chart
- Monthly Financial Report

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/expense-tracker.git
```

### Install Frontend

```bash
cd client
npm install
npm run dev
```

### Install Backend

```bash
cd server
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file.

```env
PORT=5000

MONGO_URI=your_mongodb_uri

JWT_SECRET=your_secret_key
```
